# Zeyad Ismail — Portfolio

## Files
- `index.html` — portfolio page
- `styles.css` — responsive styling
- `avatar.svg` — monogram profile graphic
- `link.txt` — add your final public website URL here after publishing

## Before publishing
1. Check that the personal details, dates, roles, and contact links are accurate.
2. If you want a real portrait rather than the ZI monogram, add your chosen image to this folder and update the `<img class="avatar" src="avatar.svg">` reference in `index.html`.
3. Open `index.html` in a browser and test the navigation, email, LinkedIn, and mobile layout.

## Publish with GitHub Pages
1. Create a GitHub repository (for example, `my-portfolio`).
2. Upload `index.html`, `styles.css`, `avatar.svg`, and `link.txt` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then save.
6. Wait for GitHub Pages to publish, then open the URL it provides and test it.
7. Replace the instructions in `link.txt` with the actual published URL and commit the change.

The final URL cannot be filled in until you publish the repository under your own GitHub account.
